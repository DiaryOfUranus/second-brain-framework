# 机思复合符号系统（v0）· 子 Skill 使用手册

> **本文件是第二大脑（second-brain）受管子 Skill 之一**，由总管在「思考成本/效能敏感」类任务中按需加载。
> 它不是理论，是一套**拿来用**的 AI 专用复合符号语言：AI 用它在内部思考时，目标是
> 「成本更低、效能不降（或更高）」。设计输入取自《编译论》机思六规格与 Q11（充分统计量链式传递），
> 但在此只是**设计约束**，不是研究对象。
>
> **背书权在用户**：所有「当下有效」结论以用户实测为准，本手册只记录已探明的甜区与边界。

---

## 一、何时启用本子 Skill（甜区与诚实边界）

本系统是「条件有效」工具，**不要无脑套用**。启用前先判断任务是否落在甜区：

### ✅ 甜区（六类，降本/防漂双胜或单胜）
1. **状态追踪 / 长链**：步数多、每步需携带的已得结论多（如账本、调试轨迹、长推理链）。
2. **合成收敛**：多条散落证据 → 单一结论（如跨文档/跨卷收敛、多源情报综合）。
3. **推导短链**：仅显**防漂移**价值（成本不显，甚至略亏）；适合易错推理。
4. **论文级长文**：输出篇幅大、内容结构化（国家/企业/系统深度分析）。
5. **异质系统对比**：把多个对象当编译体并排比较（企业对比、架构对比）。
6. **真实软件编译体**：分析真实开源/工业系统（有外部同构佐证）。

### ⚠️ 非优势区（谨慎，可能略亏）
- **聚合/通用短查询**：中文本身已紧凑，v0 无压缩空间，可能贵 ~18–35%。
- **小传递态（M<12）**：成本优势弱到边缘，甚至略亏（u 版）。
- **纯短推导（<10 步、约束一次写明后只引用）**：降本不显，靠 ⊢ 防漂。

**决策口诀**：态大、链长、需自检、需收敛 → 开；态小、题短、纯聚合 → 慎用或关。

## 二、符号系统规格

### 2.1 核心思想（一句话）
AI 自回归生成时，每步需要「上一步留下的东西」才能继续。**传统中文 CoT 把整段前文重序列化进 context（随步数变长）；本系统只向下传递一个固定大小的「充分统计量」μ**——下一步拿 μ + 新输入即可续推，不重传历史。这是成本优势的源头（对应 Q11）。

### 2.2 状态帧（canonical v0 帧格式）
每步思考产出一个状态帧：

```
F<k> | <tag> | e{实体}={值} | ∂{增量}@{实体} | μ{充分统计量} | ⊢{一致性门控}
```

- `k`：步号（F1, F2, …）
- `tag`：`n` 新实体 / `u` 更新 / `c` 主张 / `Σ` 摘要
- `e{实体}={值}`：本步落定的实体状态（数字 id 极廉，无需人类记忆）
- `∂{增量}@{实体}`：本步**充分统计增量**（只传这个，不传历史）→ Q11
- `μ{充分统计量}`：向下传递的当前态紧凑形（下一步唯一需拿走的东西，固定大小）
- `⊢{一致性门控}`：不变式自检标签（如 `Σ=T` / `c3'↩` 拒收），下帧 O(1) 校验 → 防漂移

### 2.3 精简形（v1，默认用这个）
verbose 帧在长链会「编码肥胖」（实测贵 3.3×）。默认用 v1 精简形，只留增量与 μ + 紧凑标记：

```
F14: -259→-225* | μ{余A,B,C占3位} | ⊢b==上步b+Δ
```
（`*` 首负 / `^` 最低 / `→` 依赖前驱帧；链与主题由上下文隐含，不显式写 τ/⊥/λ）

**纪律**：仅当需显式依赖图 / 开放不确定集 / 多主题混流时，才局部展开 verbose 字段。

### 2.4 组合算子与 gc/⌫ 摘要模式
- `⊕` 合并帧 ｜ `◈` 发射帧 ｜ `∇` 收割误差（噪声兜底 `∇ⁿ` / 变异待收 `∇ᵛ`）｜ `⌫` 压缩回收旧帧
- `⇩` 摘要（多帧压成 μ）｜ `?` 审计 ｜ `⚠` 标红（自检失败）
- **gc 摘要（Q11 爆发点）**：下游只需统计量时，用 `⌫` 丢弃明细，只传 μ。
  实测：信念链 M=40，v0(gc摘要) 1134 tok vs 中文全量 16130 → **省 93%**。

### 2.5 ⊢ 防漂移机制（结构属性，不靠运气）
每帧内建不变式，早期错误被下帧 O(1) 捕获；中文无内建检查 → 漂移静默传播。
已实测泛化到：算术链、推理链（分值+77 同帧捕获）、异构链（信念网络/图依赖）、
大态、跨卷冲突、跨域自由推演。故障注入均被依赖链矛盾 `⊢` 捕获。

## 三、AI 使用协议（思考循环）

```
1. 读题  → F0 = n | e{题面约束} | μ{约束集合} | ⊢约束清单=T
2. 每推一步：
      Fk = Fk-1 ⊕ ⟨e{实体}={新值}, ∂{用到的约束/推导}@{实体},
                       μ{更新后的充分统计量}, ⊢{本步不变式}⟩
      Fk →ₖ Fk+1          # 只交 μ
3. 终止： ⊥=∅ 且 μ 含完整答案 → ⇩Fk 输出中文结论
```
**关键纪律**：`μ` 必须「足够」——下一步不读任何历史也能续推。这是成本不随步数爆炸的根。

## 五、自测验收协议（申报「有效」前必跑）

| 指标 | 测法 | 成功线 |
|---|---|---|
| 成本 | tiktoken(cl100k_base) 计两种解法 trace 的 token 数 | treatment ≤ baseline |
| 效能 | 两种解法对已知答案题的正确率 | treatment 正确率 ≥ baseline |
| 防漂 | 故障注入（改某步值），看 ⊢ 是否同帧/下帧捕获 | 能被捕获 = 通过 |
| 缩放 | 长链下 token 累计增长曲线 | treatment 斜率明显低于 baseline |

**申报纪律**：
- 申报「成本更低」前，先确认用的是 v1 精简形（非 verbose）。
- 申报「效能更好」前，必须用**高维状态题**施加漂移压力（短题证不出）。
- 全部「当下有效」即可，不要求「永远最优 / 无差错」。

## 六、与其他层的关系

- **与 AI 分工治理层（见 `ai-division-governance.md`）**：本系统的 `μ` 正是**跨模型交接协议**。
  当一个工程被拆给多个 AI/模型完成时，模型间只传 `μ`（充分统计量）而非全量历史，
  可把单模型内的 O(1) 成本优势扩展到多模型流水线——这是符号系统与分工治理层的核心耦合点。
- **与工程公理约束**：本系统自身即「陈述≠执行」的范例——它带 `⊢` 质量门，不是空原则。
- **外部佐证**：开源 agent 工具 Pi（`earendil-works/pi`）的 self-extensible 与 v0 在
  「AI 原生可扩展底座」上结构同构（分处行动层 / 思考层），可作为符号系统探试的工业界旁证。
