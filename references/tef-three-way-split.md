# 三分拆框架：消解"作者把一个命题压进了三件事"的伪冲突

> 用途：当发现原命题内部出现"某条件是否必要""充分条件与必要条件打架"等表面冲突时，
> 先判断这是否为**伪冲突**——作者把三件不同性质的东西压进了一个命题。
> 这是 theory-extract-formalize 的核心差异点。

## 1. 三件不同性质的东西

| 性质 | 是什么 | 是否可证伪 | 被什么测 |
|---|---|---|---|
| **(A) 效率猜想** | "满足规格 ⇒ 获得内部纠错信号/迭代效能增益" | 是 | F-5.306 类对照实验 |
| **(B) 身份断言** | "这是首个非人宿主符号系统"（概念标签） | 否（是定义） | 概念界定，不由实验测 |
| **(C) 隐藏前件** | 宿主迭代环已达基本强度 `Strong(H)` | 否（是前置） | 实验须控制此变量 |

> 典型症状：原命题写"若满足六规格 ⇒ 获得信号"（充分条件），但放大器效应给出反例
> （弱环宿主满足规格却无信号）。表面充要冲突——实为缺了 `Strong(H)` 这个隐藏前件。

## 2. 拆解流程

1. **识别原命题**包含哪些断言，逐条列出。
2. **分类**：每条归属 (A) 效率 / (B) 身份 / (C) 前件。
3. **显式拆开**，给出三组：
   - `P1_func(H,M) ≡ Strong(H) ∧ SixSpecs(M) ⇒ Signal(H,M)`（效率猜想，条件组 `H_func`）
   - `Identity(M) ≡ SixSpecs(M) ∧ ⑥ ∧ 工作记忆解耦`（身份断言，条件组 `H_id`）
   - `Strong(H)` 作为 `P1_func` 的显式前件（独立于六规格）
4. **重算充要条件**：
   - 六规格对合格宿主（Strong）是 Signal 的**必要条件**；
   - 六规格 ∧ Strong(H) 是 Signal 的**充分条件**（域内）；
   - 弱宿主满足六规格 ⇒ 无信号，是放大器效应，**不证伪**效率猜想。
5. **把决策交回作者**：是否正式拆分、某规格（如⑥）是否纳入本体——列为待复核项，**不擅自动摇定义**。

## 3. 硬核划分模板

```
H_func = {效率猜想的被证伪条件组}      # 如 {①②③④}
H_id   = {身份断言的定义组}            # 如 {①②③④, ⑥}
O      = {可先行/部分实现项}          # 如 {⑤}
Strong(H) = 效率猜想的前置（独立于六规格）
```

## 4. 对后续阶段的方法论后果

- 若涉及证伪实验（F-5.306 类），**必须控制 `Strong(H)`**；否则证伪阈值失效。
- 在弱环宿主上测不到增益 ≠ 证伪——那是放大器效应。

## 5. 判定伪冲突的判据

- 原命题同时含"可实验测的效率"与"概念身份标签" → 几乎必然可拆。
- "若 A 则 B"与"有 A 无 B 的反例"并存 → 检查是否缺隐藏前件（如宿主环强度）。
- 拆开后若所有表面冲突消失，且每个子断言各自可独立判定 → 确认是伪冲突。
