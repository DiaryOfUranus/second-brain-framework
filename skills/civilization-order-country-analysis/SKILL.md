# 文明秩序·国家/区域分析栈

> 用户 2026-08-05 亲授的分析纵深方法。任何政治现象（如"欧美右倾"）都不能停在现象层倒推原因，必须沿此栈逐层下探到能形基底。

## 一、为什么需要这个栈（纪律）

现象层结论（"X 是因为增长停滞×分配熵增"）是对但浅——它从结果倒推，没回答"为何偏偏是这种结果而非另一种"。文明秩序框架要求：**任何政治现象必须先锚定在能形基底之上，才谈得上解释力**。

## 二、六层栈（务实子集，次序不可颠倒）

> 6 层栈是完整 18 章框架的**务实子集**，适用于快速内参。完整方法与地基门禁用下文「§二·甲 18 章完整框架」。

1. **能形基底**（标的）：支撑社会运转的所有资源总和。先盘"当前靠什么资源转、各资源 trajectory（变好/变差/不变）"。能量基底是其可被变革扩张的杠杆（核聚变等突破令原不可用资源转可用）。硬数据带坐标；方向性标"方向"。
2. **文明基因**（框架）：基底长期沉淀的稳定偏好结构——"这个文明碰到问题本能往哪边偏"。不是政策，是本能偏置。标"框架·当下有效"。
3. **制度容器**（框架）：基因约束下，制度能容纳的"变革带宽"。有些容器宽（能动大政府），有些被基因锁死（只能头痛医头）。
4. **治理架构**（框架）：容器内实际能动的工具箱 + **制度飞地**（绕开主干约束的分布式落脚点，如美国州权/美联储、法国 49.3、意大利欧盟资金条件性）。
5. **国际竞争**（OGP-I/E 视角）：外压（霸权护持 vs challenger 追赶）是强化还是瓦解现象趋势。净判断须分"强化主轴"与"不支持极端"。
6. **现象趋势**（回到起点）：被五层约束后的净结果——至此才解释"为何是这种形态而非另一种"。

## 三、关键推论（已验证于欧美右倾案例）

- 当基底走弱 + 容器锁死，政治再平衡**只能向容器内唯一能动路径走**（欧美案例＝向右，因左翼方案＝再分配/大政府在美/德/意基因+容器下物理无法通过）。
- **烈度公式**：现象烈度 ∝ 基底走弱速度 ÷ 容器可动带宽。
- **禁止用机制未支撑的宏观修复命题作前提**（如"增长修复/复苏"）——须显式标定 substrate 来源（能量基底杠杆／一次性效率红利／向未来借的幻觉），或判为条件/玄学。这是与 `voice-distill` 批判域、`prose_deslop_guard` 共享的写作纪律。

## 二·甲、18 章完整框架（完整方法，用户 2026-08-05 亲授"每一步都填进去更准"）

每一章＝对某一个**编译体**的**可编译域**做一次收敛。不对任何编译体收敛时推演无限发散；18 章叠加后国家总可编译域＝各章域交集→有限选择。这是 18 章结构存在理由（非 18 个题目罗列）。

**第零层 ε 门禁（必须先过，用户强调的地基）**：
- 文明定义含再生产能力（Ch1/Ch14："具备制度再生产能力、跨代秩序延续性的秩序生命体"）。
- ORM（Order Reproduction Mechanism，Ch9 §V7 §3.3 命题 7.3.5）＝维持核心编码跨代稳定传递的主动编译循环：编码传授→仪式强化→准入晋升→纠偏排异→反哺传授。
- ε（代谢/再生产读数）是真伪改革第一门禁（Ch17 §17.2 四步判定第一步："查 ε：低阶还有没有余力自我再生产？ε<1＝伪改革信号"）。
- **推论**：ε<1（文明无法自我再生产）→ 讨论经济（Ch10）/制度（Ch3/4）"不合适"——无 enduring 主体。这是能形基底逻辑的文明级翻版。

**18 章域收敛槽位（逐章对国家诊断）**：Ch0 导论(tier 定位)/Ch1 本体(完整性)/Ch2 基因(CS-5D)/Ch3 容器(变革带宽)/Ch4 架构(GA-IC)/Ch5 模式(可切换域)/Ch6 偏好(稳定区)/Ch7 生成(秩序涌现＝现象趋势)/Ch8 熵增(后代可编译域是否收缩)/Ch9 文教(ORM·ε 门禁)/Ch10 经济(经济可编译域)/Ch11 数字(碳硅混合态)/Ch12 特殊(FZ 前沿征兆)/Ch13 演进(高差异势流期)/Ch14 生态(国际竞争)/Ch15 基因量化(代理可读域)/Ch16 民意(反馈闭环)/Ch17 战略(真伪改革四步 S/Γ/η/ε)/Ch18 星际(千年上限)。

**6 层栈↔18 章映射**：能形基底≈Ch1/Ch8；文明基因≈Ch2/Ch15；制度容器≈Ch3；治理架构≈Ch4/5/6；国际竞争≈Ch14；现象趋势≈Ch7。

**案例文档**：`Projects/文明秩序演进实证/应用分析_欧美右倾_18章编译体填充框架_2026-08.md`（含 ε 门禁补正演示：意/德/美再生产危机＝右倾的更深地基，且右翼反移民恰侵蚀 ε 自身→自我挫败回路）。

## 四·乙、文明域专项纪律（2026-08 元基因×文明 / AS 审定循环回灌）

以下六条来自 COET v3.2 元基因×10 文明与替代性结构（AS）的审定循环，凡做文明/国别分析须默认遵守：

**乙1 · 多层级共同体 + 层级防混淆**
共同体不止于文明——国家、区域皆为合法分析单元（OCU 形态学含部落长老会/村社等传统型，L974）。任一单元须**先声明所属层级**：文明 / 区域亚型 / 国家。区域亚型必须**嵌套**进文明（中东→伊斯兰·中东型，且中东型可再分海湾租金/黎凡特/马格里布），**不得与中华/西方/伊斯兰平列于同一文明轴**。做文明比较时中东并入伊斯兰；做区域治理分析时中东型单独成行。

**乙2 · 元基因非唯一**
元基因＝L4→L3 约束投影（§3.4 L463-465），定义 CS-5D 可能性空间。同一文明内亚型可持**不同**元基因：美欧同属西方但 OGP-E/I 偏置不同；东欧斯拉夫亚型偏垂直权威/界场硬化。故基础档案（§四·甲）基因层须分两行（文明级＋亚型级），禁止把文明级元基因直接扣到具体国家。
**标签的元层级地位**：元基因标签（如"投机解脱""垂直权威"）仅为**示例性认知捷径**——编译论方法论明确反对用单标签概括整个文明（去本质主义四原则）。社会科学非精确，允许不同人/不同 AI 自行调整措辞，只要落在 CS-5D 约束投影框架内即有效；标签的正当性仅是降低理解成本（一个词易于一整套计算模型），不得把示例当排他定论、更不得反推"文明本质"。
**倾向 vs 表现（去结果论对称性）**：**基因倾向**＝约束投影在 CS-5D 可能性空间的概率分布（"更可能选某路径"），是**概率选择**而非绝对按基因行事；**基因表现**＝倾向×具体情境环境的实例化结果，`基因表现＝倾向×环境（情境）`。四类纪律：①以**成功**反推"基因强"、②以**失败**否定"基因存在"皆禁；③**高倾向≠必表达**——见更弱者亦可因环境不允许/当下另有优先/此刻不愿而未表达（有暴力倾向者不意味见弱者必施暴，更不意味见泰森必单挑）；④**倾向非永恒**——根于环境约束，环境变迁（如生产力消除地理限制）后是否延续须事实矫正；并须**反本质主义（人群层·褒贬对称·通用一切地理）**：倾向根于环境×人群交互而非族群本质（换人群留环境，倾向变），不得归为文明/族群本质特征——此戒**对称于褒贬**：把行为当"劣等本质"（贬抑）或"优越本质"（自夸/文明优越论）同错；且框架**不限于岛国**，大陆同理——生产力时序/距大陆远近/面积/资源/地质气候为联合决定项。
⑤**约束-概率-能动性（拒两端）**：框架立场＝物质约束第一性（硬边界）＋ 概率性表述（可能性空间）＋ 人在空间内选（能动）＋ 偶然性扰动（contingency）。**拒两端**：决定论/宿命论（否认能动与偶然）与制度论/意志论（以为精神/文化可超越物质硬约束）皆错。判据类比：人每日100g必死是生物必然性（非宿命论）；100g→200/300g不饿死是能动（可能）；"靠精神吃100g不饿死"＝胡说八道（否认硬约束）。另须明：**制度/文化因子多为其下游投影**，不应与物质约束并列成独立自由因（可反馈调制，非独立本源）。

⑥**制度需能形支撑（反制度排序论）**：正式制度＝**制度容器 IC**，须由足够**能形基底（RPB）/能量基底（MPB\*）**支撑；制度越复杂（自由民主/福利国）能形阈值越高。能形不足/错配时**非正式制度＝替代性结构 AS（非地理拓扑 OCU，T∈{血缘,教派,族群,庇护}）侵蚀主导正式 IC**（§14.5·乙 `D_alt≫D_core`）。禁"给制度论资排辈"（换制即飞跃）——制度是可脱离能形替换的独立自由因之误；分析须先辨**能形是否足撑该复杂度 IC**，换制前先问能形够否。经验示警：印度民主被种姓/庇护侵蚀、欧美右转显 IC 应力、阿拉伯之春回潮、非洲频政变、欧美自身内战风险。归纳靠判环境约束＋事后统计，二者必有遗漏，**须经常依新数据调整**。判断基因看**环境约束＋选择倾向＋时效**，非成败史或本质标签。

⑦**弃优劣评价·适配度·运行代价**：文明基因/制度/文化**不能用好坏优劣评价**——以"神圣海盗"之类价值标签评美国是价值化误用（正是褒贬对称之戒的反面）。但**可在中性维度上比较**（如扩张速度：西方＞中华），此非优劣判准。根本判准只有：**是否适配当下能形与整体环境**（价值＝适配度 fit，非 merit 优劣）。推论：①**消亡≠劣**——印第安文明消亡是美洲条件限制所致，非文明差；②**无永恒有用**——任何基因/制度/文化皆有时效；③**运行代价（代谢成本）**——一切运行皆支付代价，最粗糙制度亦有运行成本（耗能形）；与⑥互补：不仅需足够能形供养 IC，运行本身亦持续消耗能形。

**乙3 · AS 方案 A 标准检查（结构性盲区）**
凡做制度能力诊断（容器/架构层），必查**非地理拓扑 OCU**：种姓/黑帮/宗族＝`D(r;T)` 中 `T∈{血缘,教派,族群}` 的实例。AS **不另立新原语**——把 canonical `D_IC(r)=D_core·e^(-λr)`（L367/L777）泛化为 `D(r;T)`，补 `σ_alt`（种姓边界 σ_alt≈0，极不透）；八维审计同时采样正式 IC 梯度与 AS 梯度，报哪个 `D` 主导（种姓区 `D_alt≫D_core`）。AS 主导区恰是 canonical 的 CFZ/SCZ（L800/L2148），本就邻近，非另起炉灶。

**乙4 · 相位 taxonomy 纪律**
输出统一用 η-ε **五相**（L1878）：僵化锁定 / 真稳态 / 假性稳态 / 相变窗口 / 崩溃性解构。**退编译 / 过度编译降级为方向/过程修饰**（L1683/L1604），不得与五相并列；NEB 是**三阶段**级联（NEB₁→NEB₂→NEB₃，L1017-1025），非五阶段"级联解构"。

**乙5 · canonical 与版本断裂纪律**
baseline＝最完整版（**1128 ＋ 编译论 V7**），非简化重写（v3.1 正式稿）——否则会把"版本迭代内容丢失"误判为"框架本体盲区"。canonical / {{THEORY_SOURCE}} 各版**只读**。判某机制"缺失"前，先追跨章指针（如 Ch1 §1.4 文明八维 → V7 §1.7），二阶误判（未追指针）比版本断裂更前置。

**乙6 · 眼见为实 + 分层标注 + 两套 ε**
- 断言某术语"非 COET / 非 canonical"（如"元基因非 COET 术语""OGP-E 非原文缩写"）前，**必须 grep 源文核实**，不得凭印象否定。
- 输出每句标 **硬核（COET 元基因/D_IC/五相/NEB三阶段/OCU形态学）/ 保护带扩展（AS方案A·可归约·未增原语 / 多层级 nesting / 元基因非唯一）/ 启发值（ηεD_coreλσ 数值·非实测）**。
- ε 门禁（§二·甲 第零层）区分**文明级 ε**（宿主社会再生产，ε<1＝伪改革）与 **AS-子系统级 ε**（黑帮/宗族内部代谢可能 ε 高）；二者不可混谈，系统边界须显式指定。

## 六、禁用与诚实边界

- 基底硬数据须带坐标；基因/容器/架构为解释性框架，标"框架·当下有效"，不冒充精确测量。
- 不把"极化/右倾"当自变量（极化是结果非原因，见总账 F9 数据对冲纪律）。
- 相位用词须守 η-ε 五相（乙4）：退编译/过度编译是方向/过程修饰，NEB 是三阶段级联，不得当相位并列。
- 术语「非 COET / 非 canonical」断言前必须 grep 源文核实（乙6）；输出按 硬核 / 保护带扩展 / 启发值 分层标注，数值均标非实测。
- 伦理：仅对齐用户阅读风格（voice-distill），非冒充用户对外发文。
