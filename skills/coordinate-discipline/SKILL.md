# 坐标纪律 Sweep（Coordinate Discipline Sweep）

## Overview

本 skill 把「编译论对接工作中引用原文坐标必须带权威源 L 行号、且须 Grep 实证而非凭卡内摘要多算」的纪律，固化为可复用 sweep 工作流。该工作流已在编译数学学 M3 落卡（虚构坐标 V4 AI-15/V5 AI-6 零匹配）、M4 收口评估（漏检）、M5-B 坐标失准 sweep（清算 MATH-2/3/4 同源失准并扩展至全 8 卡＋M1 总地图，9 类坏坐标全部补正）三次实战中验证——凡不做 sweep，必出坐标失准。

**核心定理（来自 3 次失败的经验）**：对接卡中任何 `Vn Lxxx` / `AI-xx` / `§x.x` 坐标，若未当轮 Grep 实证 canonical 源，默认视为**可疑**，须 sweep 复核。摘要记忆里的行号偏移是系统性错误源（旧版章号偏移、口头编号如 AI-15/AI-6 在原文零命中）。

## When to Use

- 任一编译论对接项目进入 **M0/M1/M3/M4/M5** 任何里程碑，且文档中已写或拟写编译论原文坐标引用。
- 用户指令含「坐标失准 sweep」「清算同源失准」「补正坐标」「坐标纪律自检」。
- 收口评估（M4）与每轮攻关（M5-B）**强制前置**跑一次全量 sweep。
- 触发条件（建议立项时写入 ledger）：任何编译论对接项目 M0 启动即登记，M3 每刀落卡前、M4 收口前强制运行。

## 核心流程（sweep 五步）

1. **抽取**：用 Grep 扫本文档/对接卡/总地图中所有坐标引用形态——
   - `V\d\s+L\d+`（带卷前缀行号）
   - `AI-\d+`（口语/虚构编号，原文零命中，必查）
   - `§\d\.\d`（章节号，须核对版本章号偏移）
   - 裸 `L\d+`（无卷前缀，须补卷前缀）
2. **比对**：逐条比对 KB `coordinate-discipline/已知失准坐标速查表.md`（9 类已知坏坐标＋坏模式正则＋版本钉死）。
3. **实证**：对每处可疑/坏坐标，Grep 实证 canonical 源——路径 `{{THEORY_CANONICAL}}\编译论\原文\`（禁止从 `{{THEORY_SOURCE}}` 反向覆盖），版本严格按速查表钉死的 α/β 快照。取真实 L 行号。
4. **补正**：精确替换坏→好坐标；**不改语义、不删论证**，仅修正坐标指向。对说明文本内的坐标引用同样替换（注意 MATH-1 L5 教训：sweep 在说明文本内误替换导致自指冗余，须二次检查）。
5. **登记**：在文档 §5-A（或收口评估 §二 A 行）追加「sweep 补正 N 类：<坏→好列表>」；若发现 M4 收口曾判「无残留」而实际有漏检，显式更正为「M4 漏检」并登记（诚实纪律）。

## 诚实护栏（衔接 compile-theory-map A–H）

- **A 坐标失准**：本 skill 即 A 项的强制执行器。每轮 M3/M4/M5 须跑，未跑＝A 项不通过。
- **不抢答跨卷**：补正仅改坐标指向，不因此新增跨卷断言。
- **退化诚实**：补正后若原论证依赖坏坐标的「强锚」身份，须降级其确立度（如 ✅→🔶），不虚高。
- **留白登记**：sweep 发现的真失准（旧卷前线未建立）照常登记 🔴，不伪称已解。

## 与 compile-theory-map 关系

本 skill 是 compile-theory-map「坐标纪律」纪律项（Core Disciplines #2）的可执行子模块。compile-theory-map 负责 M0–M5 全流程框架，本 skill 负责其中「坐标必须 Grep 实证」这一最容易系统性翻车的环节的强制 sweep。两者配合：compile-theory-map 定里程碑，coordinate-discipline 在每个里程碑落地前守住坐标真实性。

## 失败模式（来自错题本，勿重蹈）

- **凭摘要多算**：M3 落卡时直接用卡内/记忆里的行号，未 Grep 实证 → 虚构坐标（V4 AI-15/V5 AI-6 在原文零命中）。
- **收口漏检**：M4 收口评估判「无残留」即结案，未跑全量 sweep → 漏检 M3 的 A 类失准。
- **范围不足**：sweep 只扫用户点名的几张卡，未扩展到全量对接文＋总地图 → 同源失准残留在其余卡（M5-B 扩展至全 8 卡才清零）。
- **说明文本漏替**：sweep 脚本只替活动锚点，未替说明文本内的坐标 → 自指冗余（MATH-1 L5）。
