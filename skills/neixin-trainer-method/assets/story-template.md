# STORY.md — 培训课程大纲模板（21 页示例）

> 用法：复制本模板，填入本课程真实内容。遵循 内训师方法论（五步法 / 勾讲练化 / 90208 / 三版制）。
> 这是 Layer A 设计产出，也是 Layer B 生成 PPT 的输入骨架（对应 3.0 版纯骨架）。

## ① 用户意图对齐

- **目标受众**：<一线员工/客服/业务引导岗等，具体到岗位层级>
- **核心目标**：学完后学员能「<记住骨架 / 守住红线 / 区分差异化要点>，在实际工作中<具体行为>」。
- **PPT 长度**：<N> 页（Hero 页占 ~20–30%）
- **视觉调性**：<商务现代 / 金融专业 / 克制结构化>
- **内容边界**：
  - 必讲：<通用流程骨架 / 合规红线 / 重点业务差异化 / 常见异常处理 / 操作口诀与工具>
  - 不讲：<系统内部架构 / 历史演变 / 监管条文逐字解读>

## ② 页面布局骨架

- **分章（<N> 页）**：
  - 导入（1–3）：封面、目录、痛点场景（勾）
  - 模块一（4–8）：<业务全景 / 流程模型 / 流程详解 / 准入前置>
  - 模块二（9–10）：<合规红线一 / 合规红线二>
  - 模块三（11–17）：<重点业务一…六 / 差异速查表>
  - 模块四（18–21）：<拦截处理·练 / 操作规范 / 口诀与工具·化 / 结束页>
- **Hero 页**：<封面 / 流程模型 / 红线一 / 重点业务差异化 / 口诀 / 结束页>，两两间隔≥1 个 supporting 页。
- **rhythm 曲线**：标注每页 peak/valley（peak=Hero 或强互动页）。
- **版式预算**：≥40% 非对称（左大图+右文字 / 上大图+下卡片 / 左标题+右内容 / 巨型数字+洞察）；
  仅 2 页用 N卡片横排且不相邻。
