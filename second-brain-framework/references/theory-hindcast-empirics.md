# 跨理论实证 Hindcast 与数据对冲 · 子 Skill 使用手册

> **本文件是第二大脑（second-brain）受管子 Skill 之一**，由总管在「给某套理论做实证验证 / 历史回测 / 把抽象 construct 落成可测量代理」类任务中按需加载。
> 它不是独立工具，是第二大脑「理论→实践操作化」工程纪律在实证层的落地——把抽象理论 construct（CS-5D / NOC / φ_distrib / DJ / ER / η …）压成**带保护带的弱代理**，用历史 hindcast 做"能不能被历史证伪"的工程检验，并用「分列不合成 + φ_distrib」处置分配类指标的数据对冲失真。
>
> **源真相在项目实证产物**（如 `{{SHARED_WORKSPACE}}\Projects\文明秩序演进实证\数据_2026Q3_v2\`）；本手册只描述调用与边界，不重复造轮子。

## 一、何时启用本子 Skill（甜区与诚实边界）

### ✅ 甜区
1. 用户要给某套理论（文明秩序演进、编译论、共振理论等）做"实证验证 / 历史回测 / 把抽象 construct 落成可测量代理"。
2. 触发词：历史回测 / hindcast / 发现问题总账 / 把理论落成数据 / 代理权重 / 数据对冲 / 分列不合成 / φ_distrib / 理论操作化 / 新旧理论对比。
3. 需要跨多个文明/案例 consolidate「结构性发现问题」并反哺数据模板（代理权重）。
4. 需要做"新旧理论版本对比、定位丢失的 construct"（版本考古）。

### ⚠️ 非优势 / 边界（诚实标注）
- 本 skill 是**实证检验方法**，不是给理论写阐释文章；若用户只要理论解读，不应加载。
- 数据是**弱代理 + 估/量级**，非精确实测；量级可测、方向可测，单点慎信。
- **hindcast ≠ 预测**：结论措辞"若当时用本框架会怎样"，不声称预测未来；诚实精度"对一半即神"。
- 前现代数据稀疏，人均 GDP 须剔除主指标，代理降级为硬代理（领土份额 / 制度行为 / 外债 / 叛乱频率）。

## 二、核心纪律（红线，违反即失真）

1. **hindcast ≠ 预测（推断-核验循环）**：用"当时可得数据"推断后来、再对照真实历史核验；措辞限定为"若当时用本框架会怎样"。
2. **估/量级标注**：所有数字带来源 + `实采/估/量级` 标签；Maddison 1990 Int$ 与 2011 Int$ 不可直比（÷1.39 归一）；vintage 差只取趋势、不取绝对值。
3. **不编造**：数据缺失标「缺」，绝不插值伪造平稳曲线。
4. **分配类指标禁止合成（数据对冲红线）**：top1% 不平等 / 债务人口 / 贸易逆差叛乱等同类分配代理，必须**分列**报告，绝不加权合成单一指数——合成会相互抵消、抹平张力（用户批判结晶）。
5. **前现代剔除人均 GDP 主指标**：古代/前现代帝国用领土份额 / 制度行为 / 外债 / 叛乱频率等硬代理；人均 GDP 仅背景或剔除。
6. **ER 永远独立变量**：外生熵增冲击不并入平滑 GDP 序列。
7. **η 地表不可测·禁编值**：社会层只追踪相位/锚点，不编绝对值。
8. **诊断不排名**：只给相对位置带，不做文明/案例排序。

## 三、标准产物结构（落到项目实证目录，如 `数据_2026Q3_v2/`）

- `_raw_历史_<文明>.md`：原始数据锚点（人口 / 人均 GDP 双 vintage / 份额 / 不平等 / 债务 / 人口结构 / 外生事件），每段标 `实采/估/量级` + 来源 + 诚实缺口。
- `历史回测_<文明>_<年代>.md`：推断-核验循环，N1–N6 类发现问题；新增 `§七/八 分配类代理分列不合成 + φ_distrib 重检`（三小节：分列不合成表 / φ_distrib 重检 / 数据对冲实证）。
- `发现问题总账.md`：跨文明 consolidate 的"结构性发现问题"主题（8 文明高度一致＝方法论教训非 artifact）。
- `v2模板_代理权重反哺.md` + `数据模板.md`：把总账反哺为可操作代理权重四表（A 现代工业民主 / B 计划经济威权 / C 前现代古代帝国 / D 帝国解体去殖民）+ 字段升级（A2 加领先信号子栏与保护带等级、B 节改五步顺序、C 节加外生 ER 情景必填）。

## 四、操作流程（M0–M4）

- **M0 立项**：确认理论源（canonical 路径）、目标文明/案例清单、步长策略（前 1500 每 25–50 年 → 1800–1900 每 5 年 → 2000 后年度）。
- **M1 理论操作化**：抽出待检验 construct（CS-5D / NOC / φ_distrib / DJ / ER / η …），逐一落「弱代理 + 点估计 + 置信区间 + 证据类型 + 保护带等级」。
- **M2 数据采集 + 全维度扫描**：实采 raw（WebSearch / Bolt-van Zanden / Maddison / WID）+ 标 vintage 差与缺口；前现代用硬代理。扫描须覆盖全 8 红线 + A2-a~i：**除分配类分列不合成(⑤)外，强制做①链式反应基底阈值扫描(A2-h：基底充足度档+缓冲层数+是否级联) ②制度形式收敛扫描(A2-i：剩余可支付基底→制度收敛方向) ③能源基政体级跃迁 ER 识别(C节 NF-6) ④OGP-I/E 依赖类型标注(NF-5)**。原 M2 仅做分配维度，全量回测(2026-08-04，8 文明+明末+阿拉伯之冬补测)补足上述四扫描；2026-08-04 末补欧洲(欧盟)2020–2025 为第 11 案，回测案例总数升至 11。**全维度扫描须按 `数据模板.md` §零「收敛推演法」四阶分析阶梯组织（能形基底→文明本体→文明基因→推演）**，把现象正确归位为症状/成因，避免把口号/极化当因果（NF-4）。
- **M3 并行回测**：派研究 agent 各自读 raw+回测起草新章节 → 主 agent **统一落盘**（保证术语一致、修冗余、对齐编号）；**严禁 agent 合成指数**。
- **M4 总账 + 反哺**：跨文明 consolidate 发现问题 → 反哺模板代理权重 → 写记忆 + brain_commit。

## 五、数据对冲处置细则（用户批判结晶）

- **φ_distrib（分配熵）**：由顶层集中度（top1% 份额 / 基尼）换算收入分配熵；top1% 越高 → 分布越不均 → 真实熵越低 → 秩序风险越高。不可量化时用"代理集合内部方向离散度"定性（各代理同向/反向，反向＝数据对冲高危区）。
- **分列不合成表**：每行 = `代理名 | 读数(估/量级+来源) | 单独趋势 | 单独承载信号`。至少覆盖 5 类：①顶层 1% 不平等 ②债务/财政 ③人口结构 ④贸易逆差/平衡 ⑤叛乱/冲突频率。缺则标缺不编造。
- **数据对冲实证三案例范式**（用本文明自身史演示合成如何漏报）：
  - **改革期合成幻觉**：后几项"好"对冲掉 inequality "坏"，读"平稳"而分配张力 silently 累积；
  - **零相关**：人均 GDP ↔ 外部冲击 ↔ 叛乱三者零相关，任何合成都会平均掉危机信号；
  - **多杀延迟**：多项同向坏时合成指数才"尖叫"，但领先信号被对冲延迟约 10–30 年。

## 六、早期理论回收纪律（防丢失件 · 版本考古）

> **⚠️ 版本考古的致命坑：Grep 对这批 UTF-8 理论文件会假阴性（2026-08-05 实证）**
> 文明秩序演进理论的 `修订稿/`、`成稿/` 等 md 文件被 Grep（ripgrep）判为二进制而**跳过中文匹配**，导致"零命中"是**假阴性、非真缺失**。曾据此误判 STES/EIM「溶解」、Ch12「FZ 前沿丢失」、并误信「ch6 存活 Lg/Lp/Lv」。**版本考古一律改用 Python 强制 UTF-8 全文扫描**（`open(f, encoding="utf-8")`，统计 `txt.count(term)`），严禁以 Grep 的"零命中"作为 construct 缺失证据。核实无误后再下"丢失"结论。

- 对比新版与旧版理论时，用 **Python UTF-8 全文扫描**的 construct 存活表（术语命中计数），核对：CS-5D / NOC 聚合公式 / φ_distrib / 分配熵 / 分配合法性 / DJ / IC三大合法性（基源/建立/认同）/ Lg-Lp-Lv 三型 / STES / EIM / CRM四大组件 / 风险对冲 / η / ER / 九步法 / FZ前沿（制度飞地/前沿区/边缘创新/负熵前沿）。
- 重点标"哪一版引入、哪一版丢失"；若新版丢失了诊断必需的 construct（如 φ_distrib / DJ / IC三大合法性 / NOC 聚合步），在下游 `数据模板.md` 另行回收（红线＋子栏）并出回流报告给理论作者。
- **Python UTF-8 复核结论（2026-08-05，文明秩序演进理论 3.0 修订稿+成稿 vs 1128）**：
  - **确证丢失（两树均 ZERO）**：φ_distrib / 分配熵 / 分配合法性 / IC三大合法性（基源·建立·认同）/ DJ 分配正义 / Lg-Lp-Lv 合法性来源三型。这恰是「合法性的可计算脚手架」，对应"过于归约导致不知道怎么算"的诊断。
  - **误判撤回（Grep 假阴性）**：STES（修订稿 7 处）、EIM（18 处）、Ch12 FZ 前沿/创新（8 处）**均存活**，非溶解/丢失；Lg/Lp/Lv 实际 ZERO（原"ch6 存活"有误）。
  - **1128 版定位**：可操作化最丰富的版本（φ_distrib 92 / IC三大合法性 67 / LgLpLv 79 / FZ前沿 14 / CRM 379 处），应列为「可操作化参照版」与 3.0 形式化版并置互补。
- 实证案例：文明秩序演进理论新版（19 章成稿）相对旧版（0.1 / 部分版 / 1128 / 2.0103 / 中转2 / 20250812）——`φ_distrib`（分配权集中度，1128 带 φ<1.0 健康 / >1.5 危机阈值）、`DJ`（分配正义性，中转2 中 OGP-I 三子维之一）、NOC 聚合公式 `Σ(OCU_i×网络权重)`（2.0103，分布被均值化处）、风险对冲机制 四项 construct **被丢弃**；8 文明 hindcast 实践证伪该"精简"。回流建议见 `文明秩序演进理论_新旧多版对比分析报告.md`（同项目目录）。完整逐章 fidelity 审计与勘误见 `文明秩序演进理论_3.0逐章对照_流失构造回收.md`（含 §9 勘误重核）。
