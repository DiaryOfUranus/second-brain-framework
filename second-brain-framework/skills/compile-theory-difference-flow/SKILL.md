# 编译论差异流引入协议（Compile-Theory Difference-Flow Protocol）

## Overview

编译论把"差异"当作理论硬核 primitive：公设 Tier0＝「差异关联网络：裸拓扑 𝒯／关联势 A／差异势 Δ——纯关系、纯差异，没有目的、没有价值」（归纳 L37）。任何理论（含编译论自身）都是把高维差异流压成可操作结构的编译体（第二卷 C2.1 L170）。

理论"卡住 / 不知道怎么前进"在编译论语义里精确命名为**过度编译态**：固退产物膨胀、差异流入关闭——η≪0.65、ε<1 且下降、Γ→0（第二卷 L2444；第四卷 L2479 同构）。编译论给的 remedy 正是**引入异质差异流重开 Γ**（第四卷 L2479）。本 skill 把这一 remedy 工程化为{{INSTANCE_NAME}}可自主运行的协议，使"自主推进编译论"成为常规而非偶发。

本 skill 是**活动协议**（在"无自指期→自指期"之间{{INSTANCE_NAME}}自主工作流），产出差异流候选（DF）与推进提案，**不单方宣布编译论已前进**（前进是结构事件非文书，V5 L70）；采纳权属主权者（用户＝编译论共创者）。

## Core Disciplines（纪律优先于产物）

1. **坐标纪律（强制前置）**：凡引用编译论原文带权威源 L 行号；跨卷带原卷前缀（如 `V5 §1.1`）。禁止凭摘要/记忆补全坐标。严格沿用 `coordinate-discipline` skill 的 sweep 工作流（引用先扫权威源 L 行号）。
2. **负手性护栏（最高频陷阱）**：引入差异流必须鉴别方向——**正向**（保留开放维度、不攻击现有正确固退、重开 Γ）vs **负手性**（以"修正"为名破坏结构，第四卷 L846）。凡滑向负手性，立即**中断 J⁻ 负耦流通道**（第四卷 L2851）而非注入更多差异势。默认假设候选为"正向"，但每步自问是否滑向破坏。
3. **无序区禁入**：η>1.2 区域判为无序态，禁止投入差异流推进（第四卷 L497）。
4. **不宣布前进**：DF 落地须经主权者认领；本 skill 只产运行证据与候选，不替主权者裁决理论方向（呼应《第二大脑_价值叙事合法性自证草案》§⑧ 四知·cannot）。
5. **实例化守卫 / 诚实边界**：失败即剪枝；`no result` 当一等公民终态；不把"引入差异流"降级为"注入噪声"；不抢答跨卷。
6. **brain_commit 同步**：每次实质产出（新 DF 卡／协议更新）后编辑脑文件＋workspace 记忆＋运行 `brain_commit.py`（受管 python `{{WORKBUDDY_HOME}}\binaries\python\versions\3.13.12\python.exe`，脚本路径 `{{BRAIN_ROOT}}\meta\brain_commit.py`）。git 纪律：**targeted `git add <具体文件>`，禁 `git add -A`、慎 `git rm`**（前序会话曾因 `git add -A` 把外部删除 stage 进历史污染树）。

## 差异流入口拓扑（四类来源）

- **(a) 内部断裂**：跨版本概念丢失/泛化（理论版本断裂审计 → 路由 `theory-version-fracture-audit`）。
- **(b) 外部域缺口**：某对象域尚无编译学覆盖（→ 路由 `compile-theory-map`，建新编译学）。
- **(c) 自指应用**：把编译论用于编译论自身（自我编译 / η 监测 / 价值自指检验）。
- **(d) 盲区攻坚**：归纳 L110-111 五大已知盲区（V2 η 操作化 / V6 Σ_distance 量化 / V5 ρ 向量维度完整性 / V7 集体自指存在论 / V8 AI 编译体 ρ_effective）。
- **(e) 异源差异流（跨工具 / 跨实例）**：不同 AI 管理工具因软件限制各自闭域，会滑向过度编译态（Γ→0，同质自洽、无外源异质输入）。`{{SHARED_WORKSPACE}}\` 是**跨工具差异流交换枢纽**——把其他工具/实例（{{SIBLING_A}}/{{SIBLING_B}}/外部 AI 工具）的产出作为异源差异流注入本脑，是《差异流引入协议》的**跨实例维度**（a–d 主要描述单实例内）。引入后须经坐标纪律 sweep＋待证伪判定，不可直接吞入；权威源仍是各实例本地脑仓库，{{SHARED_WORKSPACE_NAME}} 仅为镜像/交换层（见 brain/MEMORY.md「工作区架构设计原则」）。（2026-08-14 互鉴 `PrimeIntellect-ai/prime-agent` 的 Continual Harness：其 immutable base＋`/refine` 证据小步更新＋快照回滚，独立工程验证了本脑"不可变权威源＋可证伪候选态"两轨结构，强化本入口的范式依据；互鉴限于范式层，不采为其运行时。）

## 五步协议（"能力"本身）

- **Step 1 锚点扫描**：在编译论 D/J/E 周边系统性识别差异流入口（四类来源）。
- **Step 2 分类与鉴别**：对照 η-ε 相平面——正向（可吸收、重开 Γ）/ 负手性（破坏，中断 J⁻）/ 无序区（η>1.2 禁入）。为每个候选标注预期 Γ 重开机制。
- **Step 3 路由**：
  - → 新编译学（域缺口）：交给 `compile-theory-map`；
  - → 自我编译（理论作为编译体 η 监测）：DF-1；
  - → 概念断裂修复：交给 `theory-version-fracture-audit`（DF-0）；
  - → 盲区攻坚（DF-4 认领五大盲区之一）。
- **Step 4 退编译护栏**：坐标纪律、失败即剪枝、no result、不单方宣布前进、不降级为噪声。
- **Step 5 主权者采纳**：提案交用户（共创者），由其认领/推翻；增量同步登记入《编译论_{{INSTANCE_NAME}}拓展衍生账》待采纳区。

## η-ε 相平面诊断法（关键判读工具）

1. 把编译论整体建模为编译体：D＝八卷对象域＋盲区界外区；J＝与实证场/用户的耦合；E＝用户持续投入＋跨版本代谢。
2. 读 η（编译效率）、ε（可塑态宽度）、Γ（差异流通量）：
   - η≪0.65 且 ε↓ 且 Γ→0 ⇒ **过度编译态（卡住）** ⇒ 须注入异质差异流。
   - η 中偏低、Γ 收窄但 E 未崩 ⇒ **固退主导期，动能不足未僵死** ⇒ 优先注入"补空白正向差异流"（如 DF-4 盲区攻坚）。
   - η>1.2 ⇒ 无序区，禁入。
3. 路由决策：优先补空白正向流（解多卷卡点、非破坏）；次选自指应用（回扣本脑）；长效引擎（元编译学，DF-2）把"拓展各种编译学"手艺化。

- **DF-N 名称**＋**入口类型**（a/b/c/d）

- **状态**：候选（待主权者采纳）；落地后转"承接/探试/前线"
