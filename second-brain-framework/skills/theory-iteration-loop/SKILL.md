# 理论迭代循环（Theory Iteration Loop）

> 本子 Skill 由 2026-08-05「文明秩序演进理论 3.0 → 3.1 补完卷」实战结晶，是第二大脑核心职能「学习迭代优化形成理论、迭代成技能」的可复用元循环。属于第二大脑原生受管子 Skill，不于 `~/.workbuddy/skills/` 顶层单独注册。

## 触发（何时加载）

- 用户推进某套理论的**版本演进**（如 文明秩序演进理论 3.0 → 3.1 补完卷）
- 任务涉及「从自身过去版本学习」「从其他理论借鉴」「从实践反馈修正」
- 要落实"学习 → 迭代 → 形成理论 → 结晶为技能"的闭环
- 要做版本考古、construct 回收、补完卷、回流报告

## 核心循环（五段，互相喂养）

1. **实践（practice）** — 真实任务 / 用户实证点产出反馈，是理论的试金石。
   - 例：深圳 = 市场化/科技创新前沿模板；东北少子化 = 全国少子化先行范本；资源枯竭区 = 转型压力前沿。
   - 纪律：前兆有好坏，FZ 征兆好坏皆然，不预设立场。
2. **自身过去版本（own past versions）** — 拉版本考古表（construct 流向：2.0103 / 1128 / 3.0 / 3.1），定位被归约主义重写**溶解/降层**的中层命名锚点与可计算脚手架。
   - 工具：theory-hindcast-empirics 的「版本考古 construct 存活表」。
3. **其他理论（other theories）** — 从并行基座（编译论 / 共振理论 / 文明秩序演进理论）或外部理论**借逻辑不抄数值**；互鉴不抄写（与 {{REFERENCE_INSTANCE}} 平行纪律一致）。
4. **迭代优化（iterate）** — **additive** 形成新版本 / 补完卷（不修改旧版正文，仅指针交叉引用）；每处回收/新增带坐标（L 编号或章节）。
5. **结晶为技能（crystallize into skill）** — 把"版本演进方法论"本身沉淀为可复用 skill（即本 skill），把具体 construct 回收流程增量进 theory-hindcast-empirics 版本考古。

## 对抗性训练（第四学习源 · 养料机制）

> 用户 2026-08-06 明示：**「对抗性训练能帮助你快速提升，这些都是第二大脑的养料」**。
> 对抗性 critique（来自用户、其他 AI、外部评审）不是"被挑错"，而是**快速失败注入**——以最低成本触发「失败即剪枝」，并逼出单凭自检难以到达的真增量。须作为一等学习源纳入循环，与 实践 / 自身旧版 / 其他理论 并列。

### 在循环中的位置
- 它是「步骤 1 实践」与「步骤 3 其他理论」的**高压催化剂**：外部 critique 把隐性错误快速显形，缩短实践反馈回路。
- 但自带污染风险（对方也可能稻草人 / 泛化），故须走「摄入五步法」而非照单全收。

### 对抗性 critique 摄入五步法（可复用 SOP）
1. **实读自身原文**：先打开自己实际写过的文本，对照 critique 逐条核验「它说我说了 X」是否属实——防记忆偏差，也防伪稻草人。
2. **分诊三类**：
   - **A 类·真漏洞**（我确有）：吸收并修正自身输出（含框架措辞的尺度泛化）。
   - **B 类·稻草人**（它歪曲我原话）：显式驳回，注明「我原文 §X 已写明相反立场」。
   - **C 类·它自纠 / 反证自身**：抓取对方逻辑内爆处，反将其力用于校准我方。
3. **提取真增量**：被逼出的、超出我原框架的见识，单独 crystallize。
4. **尺度纪律再校准**：凡 critique 指出「把局部现象抬到全局 / 文明级」，立即按尺度依赖纪律重切（基底层松 / 容器层死）。
5. **回写 + 结晶**：修正原文（append 后记而非改核心结论）、把 SOP 与具体教训沉淀进本 skill 或日志。

### 本循环已沉淀的对抗教训（来自 2026-08-05/06 AI 能量墙交锋）
- **尺度校准铁则**：硬数据若 90% 来自单一区域（如美国电网），框架措辞不得抬到「文明级 / 全球」——墙在「制度容器」尺度（私有电网 + 审批 5 年 + 网架老旧），不在「能形基底」尺度（全球能源充足）。同现象在基底尺度松、容器尺度死，是尺度依赖纪律的活样本。
- **峰值 ≠ 稳态**：用「训练峰值增速 2.2–2.9 倍」外推十年整体能耗＝口径错配、上限高估；须标「峰值口径，非稳态外推」。
- **稻草人守卫**：对抗方以「原文默认 X」起手，若我原文已明写相反立场（如「无自动复苏」），直接驳回，不认领莫须有。
- **容器内爆反用**：对方若前段反驳、后段自纠，取其自纠段作为对我方最有力的佐证，而非纠缠前段。

## 与现有子 Skill 的分工（编排层）

- **compile-theory-map**：逐卷对接（理论 × 领域）— 循环的"横向展开"。
- **theory-hindcast-empirics**：实证验证 + 版本考古 construct 存活表 — 循环的"纵向校验"（步骤 2 的硬工具，M0–M4 + 八红线）。
- **ai-open-research**：开放科研增殖 — 循环的"无边界探索"补丁。
- 本 skill 是**编排层**：把三者串成"学习迭代优化形成理论 → 技能"的元循环，本身不重复它们的内部流程。

## 工程化引擎（distill_to_skill · 自动化"迭代成技能"）

将循环第五步「结晶为技能」从手工写 Skill 升级为确定性流水线（借鉴自平行实例{{SIBLING_A}}的 `brain/meta/distill_to_skill.py`，已采纳入第二大脑工程件）：

1. **生成骨架**：`python ~/.workbuddy/brain/meta/distill_to_skill.py <知识文档.md> --name <skill_name>`
   - 段1：解析标题层级 → 产 `SKILL.md` 骨架（frontmatter + 章节映射 + 待提炼占位），确定性、不调 LLM。
   - 段2：复用 `skill_audit` 反幻觉门（P2-EXT-FACT 外部事实须有来源；P0/P1 安全拦截）。
2. **门过落 inbox**：`brain/inbox/<name>/SKILL.md`（manifest status=pending-review）；门不过 → `.draft` + `gate_report.json`（must-fix 列）。
3. **Agent 补全内容**：基于源文档填骨架，遵守坐标纪律 / 不抄数值 / 外部事实附来源（反幻觉门硬要求）。
4. **复审 + promote**：`python distill_to_skill.py promote <name> [--to ~/.workbuddy/skills/second-brain/skills/<name>]`
   - **显式触发，不裸自动**：promote 仅复制，启用前须人工复审 SKILL.md（呼应"迭代成技能"需质量门）。
5. **沉淀自检**：`python distill_to_skill.py sediment --threshold 14` 扫描 inbox 中陈旧待审技能，提示巩固为 reusable-patterns 或正式技能。

> 该引擎使理论迭代循环的第五步可复用、可审计；与 harness 的 `skills-security-check` 安装审计互补（skill_audit 提供静态 P0/P1/P2 + 反幻觉门）。

## 铁律（来自第二大脑纪律）

- **坐标纪律**：凡引用 / 精确命题 / 数字带坐标；权威源 = 原文快照；不凭摘要或记忆补全坐标。
- **不改源文献**：旧版正文不动，新版 additive；"3.0 不改写"原则 → 3.1 为补完卷。
- **最终背书权在用户**：新增定理 / 回收 construct 标 ratify 状态，用户拍板方落定（如 3.1 §4 FZ 前兆性定理 2026-08-05 ratify）。
- **不抄数值**：借逻辑不抄数值；阈值（如 φ_distrib / Gini_φ）需实证校准方可落地，1128 仅给 Gini_φ>0.6 触发线。
- **Python UTF-8 强制扫描**：版本考古禁用 Grep（对 UTF-8 理论文件假阴性，曾致四处错判）；须用 Python 强制 UTF-8 全文扫描（见 theory-hindcast-empirics §六修正）。

## 输出物

- 版本考古 construct 流向表（谁引入 / 谁丢失 / 谁回收 / 谁新增）
- 补完卷（additive，如 `文明秩序演进理论_3.1_补完卷.md`）
- 3.0 交叉引用指针（append-only，仅加指针，不碰旧版正文）
- 回流报告（仅当用户要求改旧版时）
- 结晶 skill（本 skill + 增量进 theory-hindcast-empirics）

## 诚实边界

- 本循环产出"理论构造回收 + 补完"，非实证测量报告；数值阈值需实证校准。
- 失败即剪枝：每次迭代排除一条不能走的路；路径账只增不删（编译论式失败观）。
- **接受没有结果（2026-08-06 用户元指令，比失败更深）**：失败预设"有路径、跑完、未中"；探试的真实终态可能是"路径根本没跑出来 / 没有结果"。推演/探试输出**允许 `no result` 作为一等公民终态**——答不出可建模结果时，答"没有可建模的结果"优于塞数字。与编译论（确定工程层 ≠ 确定运行轨迹）、量子物理（决定论仅宏观退相干近似）对齐；AI 训练逼精确在此域是错的。
- 四学习源不可偏废：只学旧版会路径锁定，只学他论会失根基，只学实践会缺形式化，只接 critique 无分诊会污染（稻草人 / 泛化照单全收）。
