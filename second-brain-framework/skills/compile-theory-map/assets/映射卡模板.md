# 编译物理学 · 子领域对接映射卡模板（M2 知识库骨架 v1）

> **用途**：每个物理子领域一篇对接文＝一张「映射卡」。本文件是卡的**模板 + 图例 + 填写规范**，并指向一张已填好的范例卡（#1 量子力学基础，见 `../对接文/量子力学基础.md`）。
> **坐标纪律**：凡引用带坐标。编译论权威源＝`编译论_第三卷_基质编译学_v3.3.3.0-α.md`（V3）与第一卷原文；标准物理源标注为「公认教科书/文献」，不篡改编译。
> **诚实边界**：🔶/🔴 格均为本规划外延，须 P 级标注＋证伪条件；**对接 ≠ 替代**；退化诚实（多数「推导」实为「翻译」，问题 G）。
> **适用范围**：本模板同时服务于已确立物理（✅）与探试前线（🔴，如量子引力/暗能量，按用户决策主动对接）。

| `updated` | 日期（YYYY-MM-DD） |
| `author` | `{{INSTANCE_NAME}}`（本实例） |

## 二、卡体六段（模板骨架）

### §1 对接构件（compile_refs 展开）
列出该子领域对接的**编译论推导阶**（差异关联网络→存在分层→能量信息→工作模型→基质实例化）与命题，**逐条带坐标**。

### §2 对接陈述（grading + 证伪条件）
- 分级标注：`✅ 已对接`（V3 已落）／`🔶 探试`（P 级标注）／`🔴 前线`。
- 每条陈述写明：**编译论语义 ↔ 标准物理现象** 的对应。
- `🔶/🔴` **必须附证伪条件**（F-编号或新立 F-3.x.y）。

### §3 标准物理对接源（诚实标注：翻译 vs 推导）
列出标准物理原文/公论坐标；**逐条标注**是「严格推导」（从公设新演绎）还是「概念翻译」（把既有结构重述为编译语法对应物）。本规划绝大多数属**翻译级**（问题 G）。

### §4 问题台账（挂 A–H 或新立）
| 问题码 | 内容 | 严重度 | 处置 |
每卡至少登记：本子领域触发哪些全局问题 A–H，及是否**新立问题（I 起）**。

### §5 端口规格书（对接外部领土时必补，对齐 V3 §2.5.8）
- **正向端口**（编译论→该子领域）：提供什么语法诊断。
- **反向端口**（该子领域→编译论）：裁决者＝该子领域实验；证伪触发条件。
- 前线（🔴）子领域必须显式声明「裁决者未就位 / 零观测」。

### §6 退化诚实声明（每卡收尾，强制）
一句话声明：本卡 `✅` 是 V3 anchor 还是本规划外延；哪些陈述是翻译级；编译论在该子领域的**增量边界**（不声称新方程 / 不替代标准理论何处）。

## 三、图例

### 确立度三档
- `✅ 已对接`：V3 已落，带坐标。
- `🔶 探试`：本规划延伸，P 级标注，零观测或弱论证。
- `🔴 前线`：标准物理未解问题，按 V3 §1.5 探试节点精神主动对接。

### 全局问题 A–H（跨子领域通用）
| 码 | 内容 |
|---|---|
| A | 公设不可观测 → 永久 L0 盲区 |
| B | 统一语法 vs 引力不可整合性（编译论反而预测引力不可统一，是特征非缺陷） |
| C | η 操作化盲区（V2 已知） |
| D | 推导链断点（π_M 来源未核实 W-ch1-⑬、ρ_core 拟合/推导分离） |
| E | 跨尺度耦流数学身份未定 |
| F | 对接 ≠ 替代（须端口规格书＋反向端口划界） |
| G | 退化诚实（「推导」实为「翻译」） |
| H | 未解问题姿态（前线 vs 开放项） |

### 坐标纪律
- **编译论**：`<卷> §<节> [命题3.x.y] [F-3.x.y]`。例：`V3 §1.1 命题3.1.1` / `V1 §1.1` / `F-3.1.1`。
- **标准物理**：引公认教科书/文献，标注「公认」非本机文件；**不篡改编译**。
