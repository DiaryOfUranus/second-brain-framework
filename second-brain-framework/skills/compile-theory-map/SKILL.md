# 编译论逐卷对接（Compile Theory Volume Mapping）

## Overview

本 skill 把"将《编译论》某一卷（V1–V8）与某一跨域现象系统对接、登记推导链与未解问题"的研究工作流固化。该工作流已在 V3 基质编译学 / V4 生命编译学 / V5 自指编译学 / V6 认知编译学 / V7 共同体编译学 五卷连续实践中验证同构。每卷对接产出＝分领域文档库＋问题台账＋收口评估，纪律高于产物。

## When to Use

- 用户说"对应编译论第N卷""研究 Vn 与 XX 的对接""启动第N卷对接项目""继续研究下一卷"。
- 用户在某个对接项目中指令"M3 落卡 / M4 收口评估 / A 外部评审 / B 聚焦攻关 / C 归档 / D 反向校准"。
- 用户指定某卷的子领域首刀（如"INS-2 制度""ORG-1 组织"）。

## Core Disciplines（纪律优先于产物）

1. **第二大脑四值显式启动声明**：每轮实质会话/实质推进开头，当次实读 `brain/index.md`＋`brain/ledger.md`＋`brain/projects/<项目>.md`，输出四值（启动状态／脑图健康／台账／项目状态）。未声明＝异常。不可用记忆中的旧值替代当次实读。
2. **坐标纪律**：凡引用编译论原文，带权威源 L 行号（如 `L2226`）；跨卷引用带原卷前缀（如 `V6 §4.5`）。禁止套旧版章号偏移。
3. **诚实边界**：概念一致级非严格导出／不减少参数／不抢答跨卷／退化诚实／留白登记。
4. **确立度三档**：✅ 已承接（纯名词映射/本体落位，无新参数）｜🔶 探试（概念一致级工作模型，带证伪条件或挂待形式化）｜🔴 前线（真留白/无标定常数/委派归卷，须登记触发条件）。
5. **不自动推进**：M3 落卡由用户逐刀指令；M4/M5 待用户拍板。AI 不得自行跳到下一里程碑。
6. **brain_commit 同步**：每次实质产出后，编辑脑项目文件＋workspace 记忆＋脑会话日志，运行 `brain_commit.py`（路径 `{{BRAIN_ROOT}}\meta\brain_commit.py`，用受管 python `{{WORKBUDDY_HOME}}\binaries\python\versions\3.13.12\python.exe`）。

## Workflow（五里程碑）

### M0 规划
- 定位权威源：先 `ls`/`Glob` 确认 `{{THEORY_SOURCE}}/编译论/_work/编译论3.0/` 中目标卷 α 文件存在（Glob 中文路径常漏命中，改用 Grep/ls 验证）。
- 落 `规划.md`：目标／范围硬约束／责任等级／推导链 V1→Vn／子领域横轴／A–H／里程碑。
- 建项目目录（如 `编译共同体学/`：`对接文/` `知识库/` `探试/`），复制映射卡模板。

### M1 全卷对接总地图（首刀固定）
- 精读卷源开头（标题/摘要/目录/核心维度/边界声明 L48-50 类），Grep 锁定硬锚坐标。
- 落 `全<对象>对接总地图.md`：卷透镜硬锚 N 条（带 L 行号）＋子领域横轴（7 域拍板）＋推导链 V1→Vn＋M3 优先序＋A–H 图例。
- **横轴切分**：用 AskUserQuestion 让用户拍板子领域切分维度（形态/尺度 7 域 或 五模块＋特殊域 或 外部学科 7 域）。台账前缀独立（物理 I-/生命 LV-/自指 SZ-/认知 COG-/共同体 GON-），不撞他卷。

### M2 映射卡模板
- 复制六段模板（见 `references/workflow.md` 的「六段模板」），含 A–H 图例＋坐标纪律。

### M3 逐子领域落卡（用户逐刀指令）
- 每刀：实读四值 → Grep 锁定该域硬锚 → 按六段模板落 `对接文/<域>.md` → 更新 M1 §七进度表 → 同步脑文件 → brain_commit。
- 落卡时区分三类对接位：①**闭合 Vn-1 留白前线**（诚实记"移交销，卷属不撞，不伪称旧卷已解"）②**跨卷会师点**（标 🔶，不重复销旧卷前线）③**本卷主场**（核心交付物）。
- 累计同源诚实链（同一诚实姿态在不同层位显影）作为收官证据。

### M4 收口评估（用户拍板后）
- 落 `M4-收口评估.md`（形态见 `references/workflow.md` 的「M4 形态」）：诚实梯度总表（台账全量 ✅/🔶/🔴 汇总）＋A–H 映射（八类风险→台账→收口结论）＋对接度矩阵 7×四档＋同源诚实链专项＋诚实自检。
- 主战场通常是 C 操作化缺口（地球碳基归纳非宇宙常数，源文件诚实上限章如 §2.9.2 L1425）。

### M5 择路（待拍板）
- A 外部评审（{{REFERENCE_INSTANCE}} 互鉴＋业务研究反哺）／B 聚焦攻关（paired-attack 探试 Campaign：计 meter × 收费站 toll × 交接 handoff，攻操作化根）／C 归档（留该卷对接基线）／D 反向校准（骨架回流 base/编译论）。
