# 讲解词模板（演讲者备注 / 每页）

> 用法：为每一页 PPT 写一段演讲者备注，用 `tencent-local-office-edit` 的 `slide_add_notes`
> 写入（page_index 0 基）。结构遵循 勾讲练化，每页 90–170 字。

## 结构约定

按页面角色选用标签（封面/结束页可省【练】）：

- 【勾】痛点切入 / 连接学员经验（10–20秒）——回答"与我何干"
- 【讲】核心要点讲解（本页要讲什么，贴合页面真实内容，不空泛）
- 【练】互动 / 提问 / 让学员做（可选，强互动页必写）
- 【化】总结 / 行动指引 / 过渡到下页

## 示例（以"合规红线①：适当性匹配"页为例）

```
【讲】合规风控核心环节。客户风险等级≥业务要求等级才匹配放行；低于则系统拦截，不得办理。
多数业务要稳健型 C3 及以上，科创成长层要积极型 C4 及以上。
【练】请记住一句话：不匹配=拦截，不可人工绕过，也不得承诺"先办后补"。
【化】匹配页务必逐条带客户读风险提示，确认风险自担。
```

## 写作要点

1. **贴页面事实**：讲解词必须与当页真实内容一致（流程节点、数字、红线），不得编造。
2. **口语化**：写"说人话"的稿，不是页面文字的复述；多用"咱们/客户/一线"。
3. **节奏卡 90208**：每 8 分钟一个刺激（新案例/互动/提问），每 20 分钟切换活动。
4. **收尾必化**：每页末一句给学员"回去能做什么"或"下一页看什么"。
5. **不超长**：备注是提示不是台词，单页一屏内能看完最佳。
