# 第二大脑 · 个人知识 / 理论基座 OS

> 来源：`第二大脑.zip`（用户侧已运行的第二大脑实例，本环境第二大脑的方法论来源）。
> 本文件把第二大脑方法论沉淀为本技能可直接调用的**持久化知识管理操作系统**——让本技能从"单次对话的纪律"升级为"跨会话持续生长的大脑"。
> 何时加载：需要为项目建立长期知识库、归纳/沉淀理论、管理"思考基座"（已收录理论的骨架/索引/质疑）、或做跨会话记忆治理时。

## ⚠ 强制·显式启动声明（每次实质会话开场第一动作，v2.3.1 起；v2.3.4 扩为负声明）

> 来源：用户实测教训——其他 AI 管理工具存在"说了启动却不完全执行"的失败模式。静态套话可被伪造，**动态脑状态值伪造不了**；故声明须当次实读脑文件得出，未实读禁止输出（假声明比无声明更糟）。

**正负声明必居其一；声明缺失本身即异常信号（v2.3.4）。**

- **正声明（已启动）**——每次启动第二大脑，在回复开头第一动作输出：
  `【第二大脑 已启动】脑图已读｜台账活跃 N 条｜上次脑检 日期｜最近会话日志 日期｜续接：…`
  四值必须当次实读脑文件得出：`index.md`（脑图已读）／`ledger.md` 活跃条目数（非归档区）／`audits/audit-log.md` 末条日期／`sessions/` 最新文件日期。
- **负声明（未启动）**——判定本次为非实质工作、不运行五环时，仍须在回复开头输出：
  `【第二大脑 未启动】本次非实质工作，理由：…`
- **边界模糊时宁可启动五环，不用负声明挡活。**
- **位置：回复开头，不等待触发词。**

### 唤醒协议必须以本声明开头
每次有实质工作的对话开始，**第一动作**：先输出显式启动声明（正负必居其一），**再读 `index.md`** 取四值；随后按任务判定思考基座 → 读骨架 → 环 1 基座匹配检查 → 索引层下潜 → 落地台账/日志。

> **实例化守卫（防照抄他人脑）**：从他人提供的第二大脑/知识系统模板（如 {{REFERENCE_INSTANCE}} 的 `第二大脑.zip`）建本环境大脑时，**仅 seed `base/`（理论结构）与参考方法论**；`index.md / ledger.md / sessions/ / audits/ / self-model.md / MEMORY.md` 必须**按本机实际重写**，禁止照抄他人路径/台账/日志/日期。四值声明只能源于**本脑**文件——把他人脑的运行态当自己的读并声明，等于用他人状态伪造动态脑值，违反本纪律。理论内容（base/ 骨架/索引层/质疑台账）是知识，可 seed；他人的脑运行态不是。

## 〇、定位：它解决什么问题

第二大脑前三层管"对话 / 项目 / skill 生成"，第四层管"多 AI 分工"。但缺一块：**跨会话持续生长的个人知识层**——让 AI 在每次唤醒时"带着脑子"，而不是每次从零加载。

第二大脑补的就是这块。它的核心物件：

- **脑图（index.md）**：每次唤醒唯一必读文件。回答"脑里有什么、活跃项目、最近代谢、到期触发器"。
- **思考基座（base/）**：每个已收录理论的三件套——`骨架.md`（熟读后的结构残留，唤醒全读）+ `索引层.md`（命题级坐标指针，按需下潜）+ `质疑台账.md`（反向质疑，大脑不改原文）。
- **知识库（kb/）**：旗舰库 = 理论全文快照 + 检索级知识卡 + 代谢日志，四操作（学习/记忆/编译/退编译）全生命周期留痕。
- **错题本（failures.md）**：失败模式永久保留（病历不删），预防规则句式化。
- **审计（audits/）**：只增不删，机械化巡检结构/台账/过期/断档/脑图。
- **三栏制台账（ledger.md）**：待衡准事项 = 问题｜方向｜触发，触发须为可判定事件。

## 一、文件结构（落地到第二大脑工作区）

```
<brain-root>/
├── index.md              ← 脑图（唤醒唯一必读）
├── MEMORY.md             ← 长期记忆总账（用户画像/偏好/关键决策/事实）
├── self-model.md         ← 自我模型（账单脱耦声明＋能力剖面＋已知盲区）
├── ledger.md             ← 待衡准台账（三栏制）
├── failures.md           ← 错题本（症状/病因/预防）
├── patterns/             ← 模式库（预构 P 载体）
├── audits/audit-log.md   ← 审计记录（只增不删）
├── projects/             ← 各项目状态
├── base/<理论名>/         ← 思考基座：骨架.md + 索引层.md + 质疑台账.md
├── kb/<理论名>/          ← 知识库：index + 知识卡 + 原文快照 + 代谢日志
├── sessions/             ← 会话日志（YYYY-MM-DD.md）
└── tmp/                  ← 临时记忆（每对话×项目一件，关闭即退编译）
```

第二大脑默认把大脑落在：`~/.workbuddy/brain/`（**用户级稳定位，跨所有 workspace 生效**）。本环境第二大脑已迁至此（2026-07-28）；如需多脑隔离，仍可用项目级 `~/.workbuddy/<project>/.workbuddy/brain/`。

## 二、唤醒协议（wake protocol）

每次有实质工作的对话开始，**优先读 `index.md`**（若大脑已建立）：

1. 读脑图 → 知"脑里有什么、活跃项目、最近代谢、到期触发器"。
2. 按任务判定涉及哪些思考基座 → 读对应 `base/<理论>/骨架.md`（不预读索引层）。
3. **环 1 基座匹配检查（关键纪律）**：分析/评审/诊断/写作类任务，逐基座扫一句话定位再判"不涉及"。
   - **判"不涉及"须能说出该基座的"工具面"为何用不上**；说不出 → 必须读骨架。
   - 反例（已记 failure）：把"共振理论"当"抽象哲学"跳过山海经内容分析 = 框架降级；若加载其诊断判据，诊断深度高一个数量级。
4. 需要精确命题/数字/判据 → 按 `索引层.md` 坐标下潜到 `kb/<理论>/原文/` 核验。
5. 新学/新质疑 → 落地到对应台账/日志（见第四节）。

## 三、知识库四操作协议（旗舰示范见 `kb/<理论>/index.md`）

| 操作 | 动作 | 纪律 |
|---|---|---|
| 【学习】摄入 | 新资料入库：①快照版本登记 ②脚本化复制入`原文/`（不灌上下文）③结构化提取入`知识卡/`④学习日志记一笔 ⑤脑图登记 | 双标记＋坐标＋源版本＋编译日期 |
| 【记忆】存取 | 分层存储：`原文/`（逐字，除版本更新不可写）／`知识卡/`（编译产物，条目级可代谢）／日志（只增不删） | **知识卡优先，坐标下潜**；禁止全库重读（O(1) 读取） |
| 【编译】固退 | 原文 → 知识卡：一卡一目、五元数据强制、定义必须双标记 | 卡是固退产物，稳定可检索，但**可退编译**（没有定稿，只有迭代） |
| 【退编译】代谢 | 触发器：版本变更／证伪／超 90 天／用户纠正 → 待审查 → 对照权威源修订或归档 | **僵尸条目归档不删除** |

## 四、三栏制台账 + 错题本 + 审计

- **三栏制（ledger.md）**：`问题｜方向｜触发`。触发须为可判定事件；虚词（择机/适时/以后）禁止；触发即当次处置。无触发条件的待衡准 = 永久挂账（已记 failure）。
- **错题本（failures.md）**：失败模式永久保留。每条 = 症状/病因/预防（句式化）。同模式复发 ≥2 次 → 入 self-model.md 盲区节 + 触发脑检。
- **审计（audits/）**：只增不删。范围 = 结构/台账/过期/断档/脑图 5 项。可在脑检时发现的问题：登记无落点、跨卷引用无卷名前缀、双向挂账、自审盲区。

## 五、坐标纪律（最易被违反，已记多起 failure）

1. **凡引用、凡精确命题、凡数字，必须带坐标**（卷＋节号；跨卷带卷名前缀）。
2. **坐标知识的唯一权威源是原文快照**；摘要是有损压缩、记忆更劣——没有快照在手，坐标发明是默认值。
3. **涉坐标的写作/回改，开工前必须把快照（或锚点索引）递给作者；禁止作者补全坐标**（模型切换后首个涉坐标任务须重新递快照）。
4. **坐标核验检索式一律空格归一化**（`命题\s*7\.5\.6`）——判"查无"前须以宽松式复核；核验结论也须可被再核验。
5. **大脑不得直接修改理论原文**：质疑只入 `质疑台账.md`（三栏齐全才可登记），理论修订只走用户拍板的成卷管线。

## 六、与其他层的耦合

- **与第一/二层**：脑图替代"重新加载项目状态"；会话日志与 tmp/ 衔接对话级状态更新；项目状态文件即 `projects/`。
- **与第三层（skill 生成）**：归纳出的理论/模式可沉淀为子 skill（如 theory-extract-formalize 的双标记/三分拆即来自理论归纳实践）。
- **与第四层（多 AI 分工）**：跨模型交接用 v0 的 `μ`（充分统计量）；第二大脑的坐标纪律同样约束多 AI 协作时的"来源可追溯"。
- **元原则（编译论同款）**：没有定稿，只有迭代；理论自身也是编译体，自付代价、自迭代。大脑的价值在"持续生长 + 失败留痕 + 坐标可核验"，不在"一次建对"。
