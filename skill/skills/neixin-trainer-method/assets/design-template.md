# DESIGN.md — 设计系统模板

> 用法：复制本模板，定义本课程的视觉系统。所有页面共用，保证一致性。
> 配色示例为{{EMPLOYER}}金融主题，可按企业色替换。

## 画布与母版

- 画布：1280×720
- 三区母版（A/B/C）：
  - 标题区 0–120px：左侧 6px 色条 + 标题文字
  - 内容区 120–660px：主内容
  - 页脚区 660–720px：左「<公司> · <课程名>」右「<NN> / <总页>」

## 颜色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主色 primary | `#1E40AF` | 标题、页眉色条、主色块、节点主线 |
| 辅色 secondary | `#0EA5E9` | 卡片底、第二系列、分隔线 |
| 强调 accent | `#DC2626` | 「立即办理」CTA、合规红线、关键警示 |
| 文本主 | `#1E293B` | 正文主色 |
| 文本次 | `#64748B` | 次要说明 |
| 背景主 | `#FFFFFF` | 页面底 |
| 背景浅 | `#F1F5F9` | 浅底块 |
| 警示底 | `#FEF2F2` | 红区卡片底（配 `#FECACA` 边） |

## 字体

- 中文：`'Microsoft YaHei','PingFang SC','Noto Sans SC',sans-serif`
- 英文/数字：`'Arial', sans-serif`
- 标题 34–60px 加粗；正文 17–21px；页脚 14px。

## 视觉规范

- 所有 L1/L2 视觉用内联 `<svg>` 绘制，不依赖外部图片素材（保证可移植、可编译）。
- Hero 页可用全屏深色底 + 几何同心圆/线框点缀。
- 差异化对比页：左大图（SVG 流程图）+ 右文字要点。
- 数据页：巨型数字 + 洞察句（如「C3↑ / C4↑」风险等级条形）。
- 表格页：`<Table>` 二维数组，表头深蓝底白字，单元格 1px `#E2E8F0` 边框。

## 版式纪律（来自 内训师方法论）

- anti-pattern 禁忌：禁止四卡片等分、禁止装饰小图、禁止对称双栏等分（非对称≥40%）。
- 密度上限：封面/结束页≤30字；内容页 160–260字；Hero 180字左右。
- 动画克制：宣贯类可少动画；不堆砌转场。
