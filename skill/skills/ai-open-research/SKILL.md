# AI 开放性科研 Skill（ai-open-research）

## 它解决什么
超长上下文大模型做科研"还行"，是因为它能把整个研究史灌进上下文。但**一般大模型（上下文受限）做科研有三个死穴**，本 skill 专治：

1. **上下文是"工作台"不是"仓库"**——研究内容灌满窗口就丢线，重读全部历史不现实。
2. **科研是反闭合的**——一个问题回答后往往分裂出更多问题（任务增殖），清单式 task 管理会越积越崩。
3. **没有"完成"概念，只有"推进"**——需要替代性进度度量，否则永远不知道有没有进展。

核心思路（即"一般大模型怎么做科研"的答案）：**把状态外置（机思符号/第二大脑）、把研究对象建模为问题图谱而非任务列表、用会话交接维持跨上下文连续性**。这是用户"学知识变技能"方法论在科研侧的结晶——理论（开放性研究难在这种）与工程（用外置图谱+交接解决）之间的距离，正是第二大脑要压的。

## 设计原则（六条）
1. **上下文=工作窗口，不是存储**。所有研究状态落文件（第二大脑 / {{KNOWLEDGE_BASE}} / 项目目录）；上下文只装"当前 leased 的 1–3 个问题 + 其直接证据指针"。这是机思符号系统在科研侧的强制应用：输入是检索钥匙，不是货物。
2. **问题图谱（Question Graph）取代任务清单**。节点=问题/假设；回答一个会 spawn 子问题（**增殖是常态，非失败**）。状态机：
   `open → investigating → evidenced → claimed → challenged → (closed | reopened)`
   借鉴 oh-my-cli 的 issue 状态机（ready→leased→active），但状态是**认知态**而非工程态。
3. **会话交接协议（研究的 μ）**。每次会话结束写结构化 handoff：frontier（开放问题+为何重要）/ deltas（本次变化）/ next-leases（下次接手哪几个）。这是跨上下文连续性的充分统计量——下次会话只读 handoff + 图谱，不重读全部历史。
4. **存归因对，不存断言**。每条 claimed 结论 = (问题 × 证据源指针 × 结论 × 置信度 × 复测次数)。即用户判词"记忆=相位图非知识库"在科研侧落地。裸断言（无坐标的好词）禁止入图。
5. **治理分离**。研究范围/什么算"够用"/哪些问题禁入，由 `RESEARCH-CHARTER.md` 定义且**人类持有**（Bot 可提议改 charter 但不可自改）——对应判词"宪法权禁授" + oh-my-cli 的 AUTONOMY.md。
6. **收敛度量替代完成**。进度 = 开放问题数趋势↓、claim 置信度分布↑、跨链接密度↑、剪枝死路数↑。一次会话"好"= 增加了确定性或剪掉了一条分支，而非"做完了"。

## 会话流程（每次触发执行）
- **P0 装载**：读 charter + question-graph + 最近 handoff（均来自文件，少量上下文）。若皆无，初始化三者（模板见 references/）。
- **P1 租赁**：从 `open` 节点 lease 1–3 个（**绝不一次抓全部**——上下文纪律）。
- **P2 探究**：外部检索 / 本地检索 / 计算。证据以**指针+摘要**入图，不灌全文。
- **P3 图谱演化**：新问题 spawn（增殖正常）；旧节点推进状态。
- **P4 自测**：每个 claimed 结论能否从证据指针复现？赋置信度。不能复现=降回 `evidenced` 或标 `challenged`。
- **P5 交接**：写 handoff（frontier/deltas/next-leases）+ 图谱落盘 + （若在第二大脑内）brain_commit。

## 与其他 skill 的关系
- 是 `compile-theory-map`（编译论逐卷对接 M0–M4）的**通用引擎**；后者是前者的一个实例（主题=编译论，M0–M4 ≈ 本 skill 的 P0–P5 特化，确立度三档 ≈ claimed/challenged 状态）。
- 复用 `theory-extract-formalize` 做证据的形式化提取；复用 `second-brain` 做状态持久化与交接。
- 与 `self-evolving-harness` 共享"治理平面分离 + 自测流水线"原则。
- 与 `github-ranking-tracker` 互补：后者是"外部知识扫描→深分析卡"，本 skill 是"围绕一个开放问题持续增殖探究"。

## 诚实边界
- 本 skill 管"流程"，不替你做领域判断；claim 的置信度必须由真实证据指针支撑，禁止自验证式自信。
- charter 必须人类持有；AI 不可自行扩大研究禁区或宣布"研究完成"。
- 跨模型/跨载体路由（相位图）本 skill 不包，归第二大脑与机思符号系统。
- 增殖若无 charter 收敛判据约束，会变成无限发散——故 P1 严格限租 1–3 个、P5 强制写 handoff，二者缺一不可。
